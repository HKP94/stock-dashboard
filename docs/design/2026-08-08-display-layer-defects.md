## A. 데이터가 절대 안 오는 필드 (구조적 결함)

### A-1. `sma200` — 전 종목 `null` (DB엔 값이 있다) ★

| | |
|---|---|
| 증상 | 종목상세 SMA 카드의 **"SMA 120" 칸이 항상 `—`** |
| 위치 | `tabsA.jsx:1942` — `["SMA 120", s.sma200]` |
| 원인 | `export._build_price_series`가 **`LIMIT 130`** 행만 읽는데, `_sma(ser, 200)`은 `len(series) < 200`이면 `None`을 반환 → **구조적으로 항상 None** |
| 반증 | `indicators_daily.sma200`은 최근 7일 **318/318 non-null**. 데이터는 있는데 export가 안 읽고 짧은 시리즈로 재계산 |
| 부수 문제 | 라벨("SMA 120")과 필드명(`sma200`)이 불일치 — 무엇을 보여주려던 건지 계약이 모호 |
| 성격 | `atr14` 사고와 동형(CLAUDE.md §8-1 "계산 코드가 있다 ≠ 값이 저장된다"의 표시 레이어 판) |

**수정 방향(제안)**: export가 `indicators_daily`의 저장값을 읽거나, 시리즈 길이를 200+로 늘린다. 라벨/필드 계약도 함께 확정(120일선인가 200일선인가).

### A-2. `cat` — export가 빈 배열을 하드코딩 ★

| | |
|---|---|
| 증상 | 종목상세 **"주요 동인과 뉴스" 패널의 '주요 동인' 칩이 영구히 안 뜸** |
| 위치 | `export_dashboard_data.py:2450` — `"cat": []` (계산 없음, 리터럴) |
| 프론트 | `tabsA.jsx`가 66회 참조하며 칩 렌더 경로가 완성돼 있다 |
| 완화 | 빈 상태는 "주요 동인 정보 없음"으로 처리돼 **빈 박스는 아님**(CLAUDE.md 규칙 준수) |
| 성격 | 렌더 코드는 살아 있고 **데이터 배선만 없는 미완 기능** |

**판단 필요**: 이 기능을 살릴 것인가(무엇을 '주요 동인'으로 채울지 정의 필요), 아니면 렌더 경로째 제거할 것인가. Phase A에서 결정 대상.

## B. export는 내보내는데 화면이 안 쓰는 것 (미배선)

전부 **프론트 참조 0회**로 확인. 데이터는 매일 생성되지만 사용자는 못 본다.

| 필드 | 무엇 | 왜 문제인가 |
|---|---|---|
| `stock.valuationFlag` | H-1 밸류에이션 교차검증 "밸류 의심" 표식 | **설계 목적이 "대시보드에서 가시화"였는데 화면에 없다.** 현재 하이닉스·삼성 등 실제 flag가 켜져 있어도 사용자는 모른다 |
| `freshness` (최상위) | 테이블×시장 신선도 + `anyStale` | CLAUDE.md에 "프론트 배너는 후속 트랙"으로 **이미 미완 명시**. 스테일 데이터를 보면서 모르는 상태 |
| `signalAccuracy` (최상위) | 신규-F 신호 적중률 | 표본 n<30이면 null이 정상이나, **채워져도 보여줄 자리가 없다** |
| `stock.marketScoreVal`·`marketScoreDirection` | 5-B 시장 매력도 점수·방향 | 종목 카드에 시장 맥락 전달 경로 없음 |
| `stock.newsTimeline` | 최근 5건 뉴스 분석 타임라인 | 렌더 위치 없음 |
| `stock.newsCuratedCount` | 큐레이션 뉴스 개수 | 미사용 |
| `stock.safetyParts` | 안전마진 소분해(가치/퀄리티/건전성) | 스크리너 '장기보유'가 근거를 못 보여줌 |
| `earnings` (최상위) | R7 실적 일정·결과 | **내가 이번에 추가하고 UI는 안 붙였다** — 의도적 미배선(claude_pm DB 조회가 1차 목적). UI 노출은 Phase 판단 |
| `rulesCount` (최상위) | 룰 알림 개수(현재 16) | 미사용 |

## D. 감사로 못 잡는 것 (Phase A에서 봐야 할 것)

정적 대조의 한계라 **PM 기능 감사에서 반드시 별도 확인** 필요:

1. **런타임 렌더 오류** — 특정 데이터 조합에서 컴포넌트가 throw하는 경우
2. **죽은 버튼·토글** — 클릭은 되는데 요청이 안 나가거나 실패가 조용한 경우
   (전례: 관심종목 active 토글이 CORS `PATCH` 누락으로 **조용히 무반응**이었고, `curl`은 CORS를 우회해 200이라 백엔드만 보면 못 잡았다 — CLAUDE.md 기록)
3. **스테일 표시** — 값은 뜨는데 며칠 전 것인 경우(§B의 `freshness` 미배선이 이걸 못 잡게 만든다)
4. **레이아웃·반응형 깨짐**
5. **탭 간 종목 컨텍스트 유실** — 전역 `ticker` 동기화 누락
