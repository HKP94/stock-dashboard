# Wave 5-B 시장 방향 + 시장 매력도 점수 설계

> 설계 문서 (구현 아님). "지금 투자 적합한 환경인가·어느 방향인가"를 **결정론 점수 + 방향 + 신뢰도**로 평가하고, 그 점수를 개별 종목에 **신규-A1 베타 경로로만** 전파한다. 트레이딩(수급·차트)은 신규-E 별도 — 5-B는 시장 방향·점수에 집중.

## 0. 원칙

- **점수·방향·신뢰도는 코드(결정론), LLM은 해설만.**
- 시장 점수 → 종목 영향은 **퀀트 축 안의 베타 경로로만**(신규-A1에서 깔아둔 길). **3축 합산 금지**: 시장 점수가 종목 종합점수(composite)를 직접 덮지 않는다. 컨센서스·내 판단 축 불변.
- 이 점수가 종목으로 전파되므로 **정확도 최우선** — 재료 정합성·divergence 점검, 단일 지표 의존 회피, 엇갈리면 신뢰도 하향(가짜 확신 금지).
- 기존 `_detect_regime`(범주형 bull/neutral/bear)·`_attach_market_attractiveness`(우호/중립/비우호 휴리스틱)를 **연속 점수로 형식화·확장**한다(레짐의 quant 가중 조정은 별개 기존 경로 — 5-B는 composite 수식을 바꾸지 않는다).

---

## 1. 시장 매력도 점수 산출

**지역별 점수**(KR, US 각각 0~100) + 방향 + 신뢰도. (글로벌은 KR/US 공통 요소로 보조.)

### 입력 컴포넌트 (모두 결정론, 저장 데이터)
| 컴포넌트 | 입력 | 서브스코어(−1~+1) | §F7 |
|---|---|---|---|
| **지수 추세/모멘텀** | `index_daily`(KR ^KS11, US ^GSPC): 종가 vs SMA200, 50/200 기울기, 최근 N일 수익률 | 추세 위·기울기+ → +, 아래·하락 → − | 가격 기반 **진짜** |
| **변동성** | `macro_indicators` VIX(GLOBAL) | VIX<18 → +, 18~25 → 0, >25 → − | 진짜 |
| **금리/매크로** | US: FEDFUNDS·DGS10·CPIAUCSL·UNRATE / KR: KR_BASE_RATE·KR_CPI / GLOBAL: DXY·WTI | 금리·인플레 추세(디스인플레·완화 → +, 긴축·고인플레 → −), 강달러·고유가 → KR에 − 등 | 매크로는 **발표 시점만**(룩어헤드 주의, §6) |
| **시장 폭(보조)** | 활성 종목 정배열율(기존 breadth) | ≥55% → +, ≤30% → − | 진짜 |

- **뉴스 심리(`market_news_summary`)는 점수 코어에 넣지 않는다** — LLM 산출 텍스트라 점수에 들이면 "결정론 점수"가 오염된다. 뉴스는 **LLM 해설(§4)의 입력**으로만 쓰고, 필요 시 별도 결정론 폴라리티(뉴스 건수/키워드)만 **저가중 보조**로 둘 수 있다(기본은 해설 전용).

### 공식 (코드 상수 가중)
```
score = 50 + 25 * Σ( w_i * subscore_i )      # 50 기준, 0~100 clamp
기본 가중 제안(config): 추세 0.40, 변동성 0.25, 매크로 0.25, 시장폭 0.10
방향: score >= DIR_BULL(예 60) → 강세 / <= DIR_BEAR(예 40) → 약세 / else 중립
```
- 각 subscore는 [−1,+1]로 정규화(임계·z-clip), 가중·상수는 `config`/모듈 상수(하드코딩 금지).

### 정확도 가드 (신뢰도 산출)
- **컴포넌트 정합성**: 서브스코어들의 부호 일치도·분산을 본다.
  - 대부분 같은 방향 + 분산 작음 → **신뢰도 상**.
  - 찬반 혼조(예: 지수 추세 +, 매크로 −) → **중** + `divergence_note`("지수 추세는 강세지만 금리·달러는 부담 — 변동성 구간").
  - 강한 충돌 또는 **유효 컴포넌트 < MIN_COMPONENTS**(예 3) → **하**(단일 지표 의존 회피, 데이터 부족 시 가짜 확신 금지).
- 신뢰도는 `상/중/하` + `divergence_note`로 드러내고 **숫자 스칼라 하나로 뭉개지 않는다**(3축 원칙과 동일).

## 2. 저장 — 신규 테이블 `market_score` (시장 단위, asof 이력)

종목별이 아니라 **시장(지역) 단위**라 종목 테이블과 분리. `market_daily`(수집 숫자 + 종합 요약 컬럼 소유)에 섞으면 소유권이 혼탁해지므로 **분석 소유의 신규 테이블**.

```sql
CREATE TABLE IF NOT EXISTS market_score (
    asof        DATE NOT NULL,
    region      TEXT NOT NULL CHECK (region IN ('KR','US')),
    score       NUMERIC NOT NULL,          -- 0~100
    direction   TEXT NOT NULL CHECK (direction IN ('강세','중립','약세')),
    confidence  TEXT NOT NULL CHECK (confidence IN ('상','중','하')),
    components  JSONB NOT NULL DEFAULT '{}'::jsonb,   -- 서브스코어·근거 분해
    divergence_note TEXT,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (asof, region)
);
```
- **종목별/시장별 최신 조회** 패턴 유지(`SELECT DISTINCT ON (region) … ORDER BY region, asof DESC`). NUMERIC float 경계.
- `components`에 각 서브스코어·입력값·근거를 구조화(점수 책임이 코드에 있음을 추적, 사후검증).

## 3. 시장 점수 → 종목 베타 경로 반영

신규-A1이 종목 `beta`(자국 지수 대비)를 깔아뒀다. 시장 점수는 이 베타를 통해서만 종목에 작용한다.

### 메커니즘 (표시·관찰 우선, composite 미합산)
- **이번 Wave 범위 = "표시·관찰"**: 종목 카드에 **시장조정 관찰**을 둔다(composite 안 바꿈).
  - 예(약세): `시장 38점(약세) · 베타 1.5 → 시장 약세 국면에서 낙폭이 시장보다 클 수 있음(관찰).`
  - 예(강세): `시장 72점(강세) · 베타 1.5 → 시장 강세 국면에서 탄력이 시장보다 클 수 있음.`
  - 사실(점수·베타)+영향(조건부)만. 매매 단정·"줄여라" 금지(신규-D 톤·금지어 가드 재사용).
- **조정 근거 투명 기록**: `{market_score, direction, beta, effect}`를 구조화해 저장·표시(시장점수 X + 베타 Y → 조정 Z를 사람이 추적).

### composite 반영(후속·신중) — 이번엔 설계만
- 실제 composite에 베타×시장 페널티를 넣는 것은 **과도하면 종목 점수가 시장에 휘둘린다**. 따라서:
  - composite **수식 불변 유지**(3축/합산 경계). 만약 후속에 도입한다면 **별도 `market_adjusted_composite` 필드**로 원시 composite와 **나란히** 보여주고(덮어쓰기 금지), **보수적 상한**(예: 베타·시장점수 기반 ±최대 3~5점, cap)으로 제한.
  - 5-B는 "연결 경로 + 표시"까지. 강도/도입은 검증 후 별도(보수적 가중).

## 4. LLM 역할 — 시장 방향 해설만

- 입력: 코드가 만든 `score/direction/confidence/components/divergence_note`.
- 출력: "왜 이 방향·점수인지", "어디서 재료가 갈리는지", "무엇을 관찰할지" **해설만**. 점수·방향·신뢰도 **생성/변경 금지**.
- 톤: **관찰·리스크 식별**. 매매 단정("지금 사라/팔아라") 금지. 자동 집행 뉘앙스 금지.
- 위치: 기존 `enrich_market_summary`(종합) 경로 옆/안에서 `market_score`를 입력으로 받아 서술. 새 숫자 창작 금지 프롬프트 가드.

## 5. 표시

### 시장전망 탭
- **시장 매력도**: 점수(0~100) + 방향 뱃지(강세/중립/약세) + 신뢰도 + 컴포넌트 근거(추세·변동성·매크로·시장폭 막대) + `divergence_note` 경고. 단일 점수 강요 금지 톤("환경 평가일 뿐 매매 신호 아님" 유지).
- 기존 `attractiveness`(우호/중립/비우호)는 5-B 점수로 대체/통합(중복 제거).

### 종목 카드 (퀀트 축)
- 신규-A1 "시장 민감도 베타·상관" 라인 옆에 **시장조정 관찰** 한 줄(§3). composite와 분리.

---

## 6. §F7 — 진짜 계산 vs 룩어헤드 구분

- **지수 추세·모멘텀·변동성** = 그 asof까지의 가격으로 계산하는 **진짜 통계**(룩어헤드 없음).
- **매크로**: 각 asof 시점에 **이미 발표된** 값만 사용한다. 미래 발표치를 과거 점수에 끌어다 쓰면 **룩어헤드(회고)** — 금지. macro_indicators는 발표일(asof) 기준이므로, 점수 계산 시 "as-of ≤ 평가일"만 조회한다.
- 과거 시장 점수 시계열을 사후검증할 때도 각 시점은 그 시점 공개 데이터만(§F7 true 원칙).

---

## 7. 파이프라인 편입

- **점수 계산 = 분석(`pipeline_analysis`)**: 입력(`index_daily`·`macro_indicators`·정배열율)이 모두 DB에 있고 외부 수집·LLM이 없으므로 분석 소관. 지표·퀀트 계산과 같은 단계에서 `market_score` upsert. (퀀트의 `compute_regime`/베타와 인접 — 공통 시장 데이터 재사용.)
- **해설 = 종합(`pipeline_synthesis`)**: `enrich_market_summary`가 `market_score`를 읽어 LLM 해설 생성. 분석→종합 순서 유지(점수가 먼저, 해설이 나중).
- **종목 베타 경로 조정 표시**: export에서 `market_score`(지역별 최신) + 종목 `beta`로 시장조정 관찰 문자열 합성(결정론). daily/refresh 모두 분석에서 점수 갱신.

---

## 8. 구현 범위 / 비범위 (승인 후)

**이번(5-B):** `market_score` 테이블 + 결정론 점수/방향/신뢰도 엔진(정합성·divergence 가드), 분석 파이프라인 편입, LLM 방향 해설(종합), 시장전망 탭 점수·방향·근거 표시, 종목 카드 베타 경로 **관찰 표시**(composite 미변경), export 계약, 단위 테스트(공식·정규화·신뢰도 분기·divergence·베타 경로 문구·점수 미합산).

**안 한다:** composite에 시장·베타 페널티 실제 반영(후속·보수적), 트레이딩(수급·차트, 신규-E), 자동 주문, 시장 점수의 종목 종합점수 직접 덮어쓰기.

---

## 9. 미해결/검토 포인트

1. 컴포넌트 가중(추세 0.40/변동성 0.25/매크로 0.25/시장폭 0.10)·방향 임계(60/40)·`MIN_COMPONENTS` 초기값 — 과거 시장 점수 시계열 스모크 후 보정.
2. 매크로 서브스코어 매핑(금리·CPI·DXY·WTI의 우호/부담 방향·정규화) 세부 — 보수적으로 시작.
3. 시장 뉴스 심리를 점수에 (저가중) 넣을지 vs 해설 전용 유지 — 기본 해설 전용 권장.
4. 기존 `attractiveness`(env 우호/중립/비우호) 완전 대체 vs 병행 — 중복 제거 방향.
5. composite 반영 도입 시점·상한(베타×시장 페널티 cap) — 별도 검증 Wave.
