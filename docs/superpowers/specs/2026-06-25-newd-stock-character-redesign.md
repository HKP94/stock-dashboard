# 신규-D 종목 액션 재정의 설계 — "비중 판단"에서 "종목 보유성격 판단"으로

> 설계 문서 (구현 아님). 5-A(`2026-06-21-wave5-a-stock-action-advice-design.md`)를 재정의한다.

## 0. 배경과 문제

5-A 종목 액션 카드는 종목별로 **목표 비중 레인지**와 **조정 방향(늘림/유지/줄임)**을 제시한다. 이 구조가 KPH의 **집중 투자 철학과 충돌**한다. 예: 효성중공업 36% 보유를 카드가 "비중축소(줄임)"로 판단 → 사용자가 의도한 집중을 시스템이 "틀렸다"고 강요하는 모양새가 된다.

핵심 오류는 **종목 카드가 "포트폴리오 비중을 어떻게 조정하라"를 말한 것**이다. 비중·집중도는 포트폴리오 전체 맥락의 문제(포트폴리오 탭 / 5-C 소관)이지, 개별 종목 카드가 강요할 사안이 아니다.

### 재정의 방향 (KPH 확정)

1. 종목 카드에서 비중 **권고**(늘려/줄여)를 **제거**한다. 단, 집중 리스크는 **관찰**로 투명하게 표시한다 — 강요 X, 사실 O.
2. 종목 카드의 핵심을 **"보유성격(장기보유 / 모멘텀 / 단기)"**으로 바꾼다.
   - 1차(A): **기존 재료만으로** 결정론 규칙으로 성격 라벨을 낸다(새 분류기·새 수집 없음). LLM은 해설만.
   - B(변동성·모멘텀 지속성 기반 별도 분류기)는 이번 범위 아님.

## 1. 5-A 대비 유지 / 변경 / 제거

| 구분 | 5-A 요소 | 신규-D 처리 |
|---|---|---|
| **제거(표시)** | 목표 비중 레인지 `target_weight_low/high` | 종목 카드에서 **표시 제외**. DB 컬럼·계산은 보존(2·4·6장). |
| **제거(표시)** | 조정 방향 `weight_action`(늘림/유지/줄임) | 종목 카드에서 **표시 제외**. DB 보존. |
| **변경** | `direction`(매수/비중확대/유지/비중축소/매도) | 종목 카드는 **표시 신호(매수/관망/축소)**(기존 `display_signals`)만 등급으로 노출. 비중 지시형(비중확대/비중축소)은 카드에서 안 보임. `direction` 컬럼 자체는 DB 보존(이력·5-C용). |
| **유지** | 진입/이탈 구간 `entry_zone`/`exit_zone` | 그대로(종목 자체의 기술적 위치 — 비중 강요 아님). |
| **유지** | 신뢰도 `confidence`(상/중/하) | 그대로(재료 일치도). |
| **유지** | 지지/반대 재료 `supporting_factors`/`opposing_factors` | 그대로. |
| **유지** | `divergence_note` | 그대로. |
| **유지** | `current_weight`(파생·저장) | 그대로 — 단, "조정하라"가 아니라 **집중 리스크 관찰의 입력**으로만 쓴다. |
| **추가** | 보유성격 라벨 + 근거 | `hold_character` + `hold_character_basis`(3장). |
| **추가** | 집중 리스크 관찰 | `concentration_note`(4장). |

핵심: **데이터는 아무것도 제거하지 않는다.** 비중 관련 숫자(target_weight, weight_action, direction)는 계산·저장을 계속하되 **종목 카드 표시 경계에서만 뺀다**(데이터 보존 + 포트폴리오 탭/5-C 재사용 여지).

## 2. 보유성격 판단 규칙 (A) — 결정론

### 2-1. 입력(전부 기존 재료, 추가 수집 없음)

| 재료 | 출처(현존) |
|---|---|
| 수동 분해 단/중/장 매력도 | `aiDecompositionSummary.labels` = `{단/중/장 → 매력적·중립·비매력}` (4-D-3) |
| 퀀트 모멘텀 팩터 | `f.m`(0~100), 합성 `comp` |
| 추세/정배열 | `align`(정배열 bool), `slope`(추세기울기 %) |
| 안전마진(가치·퀄리티·건전성) | `safety`(0~100, §F4-6) |
| 진입구간 근거 | `entry_zone`(SMA 기반, 5-A `derive_entry_exit_zones`) |
| 단기 이벤트 | 최근 2일 `news_raw` 존재 / 큐레이션 / RSI 과열·침체 |

### 2-2. 규칙 (우선순위 — 첫 매치가 1차 성격, 코드 상수 임계값)

집중 투자 철학상 **장기보유를 먼저 본다**. 한 종목이 여러 성격을 가질 수 있으므로, **1차(primary) 라벨 + 보조(secondary) 태그**로 둔다. 라벨은 결정론 함수가 정하고 LLM은 못 만든다.

```
상수(config 추출): LONG_SAFETY_FLOOR=65, QUALITY_FLOOR=60,
                   MOM_FLOOR=60, SLOPE_FLOOR=0.0, NEWS_EVENT_DAYS=2

primary 라벨 결정(첫 매치):
1) 장기보유  if  manual.long == "매력적"
                 OR (safety >= LONG_SAFETY_FLOOR AND f.q >= QUALITY_FLOOR)
2) 모멘텀    if  align == True AND slope > SLOPE_FLOOR AND f.m >= MOM_FLOOR
3) 단기      if  manual.short == "매력적"
                 OR 최근 NEWS_EVENT_DAYS일 내 뉴스 이벤트
                 OR RSI 과열(>=70)/침체(<=30)
4) 정보부족  else  (위 어느 것도 강하게 충족 못 + 데이터 빈약)

secondary 태그: primary 외에 위 1)~3) 조건을 동시 충족하는 항목을 보조로 표기
                (예: primary=장기보유, secondary=[모멘텀]).
```

- **장기보유**: 펀더멘털 확신 우위. 성격 서술 톤 — "변동성 견디며 보유, 진입은 분할·하단, 이탈은 펀더멘털 훼손 시".
- **모멘텀**: 추세 우위. — "추세 추종, SMA 지지 재확인 시 진입, 추세선 이탈 시 점검".
- **단기**: 촉매/이벤트 우위. — "짧은 호흡, 촉매 소멸·타이트한 이탈 점검".
- **정보부족**: 라벨 보류. "성격 판단 보류(데이터 부족)" — 가짜 확신 금지.

### 2-3. 근거 기록 `hold_character_basis`

어떤 재료가 라벨을 밀었는지 구조화(3축 비합산 — 합산 점수 만들지 않음):

```json
[
  {"source":"수동분해(장)","value":"매력적","effect":"장기보유 결정"},
  {"source":"안전마진","value":"71","effect":"장기보유 지지"},
  {"source":"모멘텀팩터","value":"64","effect":"모멘텀 보조 태그"}
]
```

LLM은 이 라벨+근거를 입력받아 **해설(rationale) 한 단락**만 쓴다. 라벨 생성·변경 금지.

## 3. 집중 리스크 "관찰" 필드 (`concentration_note`)

### 3-1. 무엇을 관찰로 서술하나

- **현재 비중** `current_weight`(이미 5-A에서 파생·저장).
- **베타** — **신규-A에서 도입 예정**. `compute_quant` 내부에 beta 계산은 있으나 종목 카드 노출 필드는 아직 없음. 없으면 베타 문구 **생략**(graceful degrade), 신규-A 이후 추가.
- **집중도 표현** — "포트폴리오 상위 비중 구간" 같은 사실 서술.

### 3-2. 발화 트리거(상수)

`current_weight >= CONCENTRATION_OBSERVE_PCT`(예: 15%)일 때만 관찰 노트를 채운다. 미만이면 `concentration_note = null`(노트 없음). **이 임계값은 발화 트리거일 뿐 비중 상한·강제가 아니다.**

### 3-3. 톤 가이드 — "줄여라"로 안 읽히게

**허용(사실·조건부·관찰):**
- "현재 비중 36% — 단일 종목 비중이 높아 **시장 급락 시 포트폴리오 변동성에 크게 기여**합니다."
- "베타 1.4 — 시장 대비 변동 폭이 큰 편." (베타 도입 후)
- "집중에 따른 변동성은 **의도된 선택일 수 있습니다. 판단은 본인 몫.**"

**금지(지시·강요):**
- "비중을 줄이세요 / 축소 권고 / 매도하세요 / 36%는 과합니다 / 적정 비중은 N%".
- 목표 비중 숫자 제시, 조정 방향(늘림/줄임) 단정.

**표현 규칙(코드/프롬프트 양쪽):**
- 주어를 "이 종목/이 비중"으로 두고 **조건부 변동성**만 서술("~시 ~할 수 있음").
- 항상 "판단은 본인" 류의 비강요 단서를 동반.
- `concentration_note`도 결정론 템플릿(비중·베타 수치 삽입)으로 1차 생성하고, LLM은 매끄럽게 다듬되 **수치·금지어 가드** 적용. 금지어 필터를 파서에 둔다.

### 3-4. UI 배치(관찰임을 시각적으로 분리)

종목 카드 안에서 **회색/관찰 톤의 별도 소섹션**("관찰 · 집중 리스크")으로 둔다. 방향 뱃지처럼 강조하지 않는다(지시로 오인 방지).

## 4. DB 스키마 변경 (추가만, 보존 우선)

`stock_action_advice`에 **nullable 컬럼 추가**(기존 행·컬럼 보존, 마이그레이션은 ADD COLUMN만):

- `hold_character TEXT CHECK (hold_character IN ('장기보유','모멘텀','단기','정보부족'))`
- `hold_character_basis JSONB NOT NULL DEFAULT '[]'::jsonb`
- `hold_character_secondary JSONB NOT NULL DEFAULT '[]'::jsonb` — 보조 태그 목록
- `concentration_note TEXT`  (nullable — 트리거 미만이면 null)

**보존:** `target_weight_low/high`, `weight_action`, `direction`은 **컬럼 유지 + 계산 유지**. 표시 경계(export/UI 종목 카드)에서만 제외한다. 베타 컬럼은 신규-A가 도입한다(이 설계는 자리만 예고). `UNIQUE (ticker, asof)`·하루 1건 이력·`created_at`은 5-A 그대로.

## 5. UI 변경 (종목상세 액션 카드)

`ActionAdviceCard`(`tabsA.jsx`)를 **"종목 성격 · 액션"** 카드로 재구성.

**새 표시 순서:**
1. **보유성격 뱃지**(장기보유/모멘텀/단기/정보부족) + 보조 태그 + 근거 한 줄. (카드의 리드)
2. **표시 신호**(매수/관망/축소, 기존 `display_signals`) + **신뢰도**(상/중/하). (등급 — 허용)
3. **진입 구간 / 이탈 구간**. (유지)
4. **지지 재료 / 반대 재료** + **divergence**. (유지)
5. **관찰 · 집중 리스크** 소섹션(회색 톤): `concentration_note`가 있을 때만. (3장)
6. 과거 제언 토글(이력). (유지)

**제거:** "목표 비중 X~Y%" 그리드, "조정 방향(늘림/줄임)" 뱃지. 데이터는 DB에 남되 카드에서 안 보인다.

**문구 원칙:** 근거 기반 관찰 톤, 자동 집행·비중 강요 뉘앙스 금지, 숫자 옆 재료 출처 노출. 내부 `.py` 경로 노출 금지.

## 6. 포트폴리오 탭과의 경계

- **종목 카드(신규-D)** = 종목 **자체의 성격**(장기/모멘텀/단기) + 종목 단위 진입/이탈/신뢰도 + 집중 리스크 **관찰**(사실 서술).
- **포트폴리오 탭(5-C 예정)** = 비중·집중도의 **관리·판단 도구**(목표 비중, 리밸런싱 시나리오, 전체 변동성 기여). 비중 "조정"은 여기 소관.
- 그래서 5-A가 계산하던 `target_weight_*`/`weight_action`을 **삭제하지 않고 보존**한다 — 포트폴리오 탭(5-C)이 전체 맥락에서 활용할 수 있는 입력으로 남긴다. 종목 카드는 안 보여줄 뿐.

---

## 7. 행위 보존 경계

- 5-A의 **결정론 숫자**(진입/이탈 구간 SMA 근거, `current_weight` 파생, `confidence` 산출, `divergence`)는 그대로 유지.
- **숫자는 코드, LLM은 서술** 원칙 유지 — 보유성격 라벨·집중 노트도 결정론 규칙/템플릿이 만들고 LLM은 해설만.
- **3축 비합산** 유지(매력도 3축·수동 단/중/장을 단일 점수로 합치지 않음). 보유성격은 라벨이지 점수가 아니다.
- §F7(true/retrospective), DB NUMERIC 읽기 경계 float 변환, **종목별 최신 조회**(글로벌 max(asof) 금지), 시크릿 비저장 모두 유지.
- 파이프라인: 종합 단계(`pipeline_synthesis`/`stock_action_advice`)에 라벨·관찰 산출을 **추가**하되 종목 단위 try/except·배치 예산·이월 기록 보존.

## 8. 구현 범위 / 비범위 (승인 후)

**이번(신규-D, A)에 한다:**
- 결정론 보유성격 분류 함수(2장 규칙) + 근거 기록.
- 집중 리스크 관찰 노트(결정론 템플릿 + LLM 다듬기 + 금지어 가드).
- 스키마 ADD COLUMN(4장).
- export·종목 카드 UI 재구성(비중 권고 표시 제거, 성격·관찰 추가).
- 단위 테스트(분류 규칙 분기, 트리거 임계값, 금지어 가드, export 최신/이력, 표시 제외 확인).

**안 한다:**
- B: 변동성·모멘텀 지속성 기반 별도 분류기.
- 베타 수집·노출(신규-A 소관 — 자리만 예고).
- 포트폴리오 리밸런싱/목표 비중 도구(5-C 소관).
- `target_weight_*`/`weight_action`/`direction` 컬럼·계산 **삭제**(보존).
- 자동 주문.

## 9. 미해결/검토 포인트 (구현 전 확정)

1. `hold_character` 임계값(LONG_SAFETY_FLOOR=65, MOM_FLOOR=60 등) 초기값 — 스모크로 보유 7종목 라벨 분포 보고 후 보정.
2. `CONCENTRATION_OBSERVE_PCT`(15%) 초기값 — KPH 집중 스타일상 더 높여야(예: 20~25%) 할 수 있음.
3. 베타 도입(신규-A) 전까지 집중 노트는 비중만으로 서술 — 베타 없는 1차 문구 확정 필요.
4. 보조 태그를 카드에 얼마나 노출할지(리드만 vs 보조까지).
5. `direction` 컬럼을 카드에서 빼면, 기존 `actionAdviceHistory` 과거 이력 표시에서 옛 `비중축소` 라벨을 어떻게 보일지(이력은 당시 그대로 보존·표기 권장).
