# 신규-A2 매력도 3축 종합 등급 + 해설 + 괴리 설계

> 설계 문서 (구현 아님). 매력도 3축(퀀트·컨센서스·내 판단)을 **하나의 통합 카드**에 묶어 ① **매매 기준이 되는 명확한 등급**(결정론, ★핵심), ② **등급을 받치는 3축 종합 해설**(LLM), ③ **3축 괴리 식별**(결정론)으로 보여준다. KPH 강조: "결국 최종 점수 보고 매매한다 — 매매 기준 되는 명확한 추천을 원한다." 단, **등급은 점수 합산이 아니라 축들의 정렬 패턴에서 도출**한다.

## 0. 원칙

- **등급·숫자·괴리 판정은 코드(결정론), LLM은 해설만.** 신규-D 톤(매매 단정 회피)이되 **등급 자체는 모호하지 않고 명확**하다. ("관심/관찰/주의" 같은 모호 라벨 금지 → 매수/관망/축소.)
- **단일 통합점수 금지**(확인편향·축 뭉개기 방지). 3축은 여전히 **나란히** 표시(`AxesCard` §매력도 3축 원칙 유지). 등급은 그 **위의 결론 레이어**이지 가중평균 한 숫자가 아니다.
- **등급은 "축의 방향(강/중/약)" 정렬 패턴**에서 규칙으로 도출한다. 축 원시값(컴포지트 73·상승여력 18%·별점 4)을 **평균/합산하지 않는다** — 각 축을 강/약/중립으로 분류한 뒤 그 **방향들의 조합**만 본다(방향 투표이지 값 합산이 아니다).
- **시장 점수(5-B)·베타(A1)는 퀀트 축 경로로만** 등급에 작용한다(3축 분리 유지, composite 합산 금지). 컨센서스·내 판단 축은 불변.
- **발굴 우선**: 전체 종목을 등급순 정렬·필터해 "지금 매수 등급 종목"을 쉽게 찾게 한다(KPH 핵심 요청).

## 1. 입력 — 3축 레벨화 (기존 경계 재사용)

각 축을 **강/중/약**(또는 결측)으로 분류한다. 임계는 이미 `AxesCard._level`(tabsA)·export에 존재하므로 **그대로 재사용**(새 임계 창작 금지, 코드 상수화).

| 축 | 출처 | 강 | 약 | 중립 | 결측 |
|---|---|---|---|---|---|
| **퀀트** | `quant_scores.composite` | comp ≥ 60 | comp < 40 | 40~60 | 없음(항상 존재) |
| **컨센서스** | 상승여력 `up=(목표가/현재가−1)` | up ≥ 20% | up < 5% | 5~20% | 목표가 없음 → 결측 |
| **내 판단** | `stock_notes` 별점 attractiveness | ≥ 4 | ≤ 2 | 3 | 미입력 → 결측 |

- 결측 축은 **0점이 아니라 "축 없음"**(3축 원칙). 등급 산출에서 빠지고 신뢰도를 낮춘다.
- **퀀트 축 보정(시장·베타 경로, §3)**: 시장 점수·베타로 퀀트 축 레벨을 **한 단계 보수화만** 한다(강→중). 다른 축·등급 직접개입 없음.

---

## 2. 등급 산출 — 정렬 패턴 규칙 테이블 (★핵심, 결정론)

방향 투표: 강=+1, 약=−1, 중립/결측=0. `strong`=강 축 수, `weak`=약 축 수, `present`=존재 축 수(결측 제외).

| 패턴 | 등급 | 신뢰도 | 비고 |
|---|---|---|---|
| present≥2, **모든 존재 축 강** (weak=0, strong=present) | **매수** | 상 | 완전 정렬 |
| strong≥2, weak=0 (일부 중립 허용) | **매수** | 중 | 우세 정렬 |
| strong≥1 **AND** weak≥1 (축 충돌) | **관망** | 하 | divergence 강조(§4) |
| strong=0, weak=0 (전부 중립) / present≤1 | **관망** | 하 | 방향 불명·근거 부족 |
| weak≥2, strong=0 | **축소** | 상(weak=present) / 중 | 다수 약 |
| weak≥1, strong=0, 나머지 중립 | **축소** | 중 | 우세 약 |

규칙 요지(투명 공개용 의사결정):
```
if strong>=1 and weak>=1:        등급=관망, 신뢰도=하   # 충돌 → 확인 우선
elif strong>=2 and weak==0:      등급=매수, 신뢰도=(상 if strong==present else 중)
elif weak>=2 and strong==0:      등급=축소, 신뢰도=(상 if weak==present else 중)
elif strong==1 and weak==0:      등급=관망, 신뢰도=중   # 한 축만 강 → 약한 매수 아님, 관망
elif weak==1 and strong==0:      등급=축소, 신뢰도=중
else:                            등급=관망, 신뢰도=하   # 전부 중립/결측
```
- **어휘는 `display_signals`와 정합**(매수/관망/축소). 임계·문구는 모듈 상수(하드코딩 금지).
- **합산 아님 명시**: 위는 축 **방향의 개수**만 센다. 컴포지트·상승여력·별점 숫자를 더하거나 평균하지 않는다.

### display_signals(횡단면 신호)와의 관계
- 기존 `display_signals`(퀀트 컴포지트 **횡단면 백분위** 70/30 → 매수/관망/축소)는 **퀀트 축 내부의 상대 위치**다.
- A2 등급은 **3축 정렬 결론**(종목 자체). 둘은 다른 층위 — A2 등급이 카드 **헤드라인**, 횡단면 백분위는 퀀트 축 안에 남는다. UI에서 둘을 같은 줄에 섞어 혼동시키지 않는다.

## 3. 시장 점수·베타 → 등급 (퀀트 축 경로로만)

신규-A1 `beta`·Wave 5-B `market_score`를 **퀀트 축 레벨 보정**으로만 반영(3축 분리·composite 미합산 유지).

- 약세장(`market_score` 약세) **AND** 고베타(β≥1.2)이고 퀀트 축이 "강"이면 → 퀀트 축을 **"중"으로 한 단계 보수화**(시장 역풍에 낙폭 클 수 있음). 결과적으로 매수 등급이 관망으로 내려갈 수 있다.
- 강세장+고베타는 등급을 **올리지 않는다**(상방 과신 금지 — 보수 비대칭).
- 보정은 **퀀트 축에서만**. 컨센서스·내 판단 축은 절대 건드리지 않는다.
- 보정 적용 여부·근거를 `grade_basis`에 기록(시장점수 X·β Y → 퀀트 축 강→중 → 등급 Z). 사람이 추적 가능하게.

---

## 4. 3축 종합 해설 (LLM) — 등급의 근거

- 입력: 코드가 만든 `grade/grade_confidence` + 3축 레벨 + 괴리 판정(§5) + 보유성격(신규-D) + 시장 베타 관찰(5-B).
- 출력: 등급 옆 **한 단락** — "왜 이 등급인지, 축이 어떻게 정렬/충돌하는지, 무엇을 확인할지". 예: *"퀀트·컨센서스는 강하지만 내 판단만 유보 → 두 축이 가리키는 상승 근거를 직접 확인 권장."*
- **금지**: 등급·숫자 **생성/변경**. "73점" 같은 합산 점수 창작. 매매 단정("지금 사라/팔아라"). 등급은 코드 값 그대로 인용만.
- 위치: 기존 액션 제언(Wave 5-A `stock_action_advice` rationale) 경로 재사용 — 같은 종합 단계에서 등급을 입력으로 받아 해설 생성. 신규-D `is_observation_clean` 류 가드 재사용(가치판단·지시어 차단).
- 키 없음/실패 → 결정론 템플릿 폴백("퀀트 강·컨센서스 약 — 확인 필요" 식 규칙 문장). 폴백을 UI에 "분석 실패"로 노출 금지(§폴백 규칙).

---

## 5. 3축 괴리 식별 (결정론) — 해설의 입력·신뢰도 하향

- 축이 엇갈리는 종목을 **결정론으로 판정**(확인편향 방지). 기존 export `diverge`(퀀트↔컨센서스 큰 엇갈림, `comp≥60∧up<5` 등)를 **3축 일반화**: 강∧약이 동시에 존재하면 괴리.
- 괴리 강도 = 동시에 존재하는 강·약 축 간 거리(레벨 차). 클수록 **등급 신뢰도 하향**(§2에서 충돌=하) + 해설에서 **divergence 강조**.
- 산출물: `divergence_note`(이미 `stock_action_advice`에 존재) 재사용 — "퀀트 높음 ↔ 컨센서스 낮음 — 확인 필요" 식 사실 문장. 해설(§4)이 이 노트를 받아 풀어 쓴다.

## 6. 저장 — `stock_action_advice` 확장(신규 테이블 없음)

이미 `UNIQUE (ticker, asof)` 일 단위 시계열 + `hold_character`/`concentration_note`/`divergence_note`/`rationale`을 가진다. 등급은 같은 레코드에 **컬럼 추가**(테이블 신설·중복 금지).

```sql
ALTER TABLE stock_action_advice
  ADD COLUMN IF NOT EXISTS grade            TEXT,    -- '매수'|'관망'|'축소'
  ADD COLUMN IF NOT EXISTS grade_confidence TEXT,    -- '상'|'중'|'하'
  ADD COLUMN IF NOT EXISTS grade_basis      JSONB DEFAULT '{}'::jsonb;  -- 축 레벨·패턴·시장보정 근거
```
- `grade_basis`에 3축 레벨(강/중/약/결측)·strong/weak 카운트·시장 보정 적용 여부를 구조화(점수 책임이 코드에 있음을 추적, 사후검증).
- export는 종목별 **최신** 조회(`DISTINCT ON (ticker) … ORDER BY ticker, asof DESC`). NUMERIC float 경계.
- 기존 비중 컬럼(`target_weight` 등)은 신규-D대로 **보존·표시제외** 유지. 등급은 그와 별개.

## 7. 표시 — 통합 카드 + 발굴

### 종목상세 통합 카드 (3축 위 결론 레이어)
- **헤드라인: 등급 뱃지**(매수=초록/관망=회색/축소=빨강) + 신뢰도(상/중/하). 명확하게.
- 그 아래 **3축은 그대로 나란히**(`AxesCard` 유지 — 퀀트·컨센서스·내 판단 + 출처 라벨 + 결측 표기). 등급이 축을 대체하지 않는다.
- **해설 한 단락**(§4) + **괴리 경고**(있으면). "등급은 매매 신호일 뿐 자동 집행 아님 / 투자 자문 아님" 면책 톤 유지.

### 발굴 — 스크리너 등급 정렬·필터 (KPH 핵심)
- 스크리너 탭(tabsB)에 **등급 컬럼** + **등급 필터**("매수만"/"관망"/"축소") + 등급순 정렬. "지금 매수 등급 종목"을 한눈에.
- export 종목 dict에 `grade`/`gradeConfidence` 추가(기존 `filterStocks` 패턴 재사용). 신뢰도 '상' 매수를 우선 노출(정렬 2차 키).

---

## 8. 합산 경계 (절대) · §F7

- **단일 통합점수(가중평균 73점) 금지.** 등급은 정렬 패턴(방향 투표)에서, 점수 합산 아님.
- **3축은 따로 표시 유지**(divergence 보존). 등급은 그 위 결론 레이어.
- **시장·베타는 퀀트 축 경로로만**(§3), 컨센서스·내 판단 축 불변. `composite` 수식 불변.
- **§F7**: 퀀트·컨센서스·베타는 그 asof까지의 저장 데이터로 계산(진짜, 룩어헤드 없음). 시장 점수의 매크로 입력은 5-B대로 발표시점(asof≤평가일)만. 등급도 그 시점 공개 데이터만으로 재현 가능.

## 9. 파이프라인 편입

- **등급 산출 = 결정론, 종합(`pipeline_synthesis`) 액션 제언 단계 안**: 입력(3축·시장점수·베타)이 분석에서 이미 DB에 적재되므로, 등급은 액션 제언(Wave 5-A) 직전/안에서 결정론 계산 → `stock_action_advice` upsert. LLM 해설은 같은 단계에서 등급을 입력으로.
  - *(대안: 등급만 분석 단계에서 계산해 저장하고 해설만 종합 — 입력 의존성상 종합 편입이 단순. 구현 시 확정.)*
- daily/refresh 모두 등급 갱신(액션 제언 경로를 따른다).

---

## 10. 구현 범위 / 비범위 (승인 후)

**이번(신규-A2):** 3축 레벨화(기존 임계 재사용) + 등급 규칙 엔진(정렬 패턴, 시장·베타 퀀트축 보정) + 괴리 일반화 + `stock_action_advice` 컬럼 확장 + LLM 3축 해설(폴백 포함) + 통합 카드 표시 + 스크리너 등급 정렬·필터 + export 계약 + 단위 테스트(등급 규칙 테이블 전 분기·결측 처리·충돌→관망·시장보정 비대칭·합산 미발생·괴리 판정).

**안 한다:** 단일 통합점수 도입, composite에 등급/시장 직접 합산, 자동 주문, 트레이딩(수급·차트, 신규-E), 등급의 백테스트(별도 검증 Wave).

## 11. 미해결/검토 포인트

1. 등급 규칙 임계(strong/weak 카운트 분기)·"한 축만 강 → 관망" 정책 — 보유 7종목+대표 종목 스모크 후 보정.
2. 시장·베타 퀀트축 보정 강도(β≥1.2 한 단계 보수화)·비대칭(강세장 미상향) — 변동성 장세에서 등급이 상식적인지 검증.
3. 결측 축이 많은 종목(컨센서스·내 판단 둘 다 없음 → 퀀트 단독)의 등급 신뢰도 처리 — 기본 '하'.
4. 통합 카드와 기존 `display_signals` 횡단면 신호의 화면 배치(중복 인상 방지).
5. 등급 산출을 분석 vs 종합 어느 단계에 둘지(§9 본안 vs 대안) — 입력 의존성 기준 구현 시 확정.
