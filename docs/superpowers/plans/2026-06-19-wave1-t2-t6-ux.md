# Wave 1 T2–T6 UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve news sorting, stock discovery, sector editing, judgment history, and Korean display labels without changing internal data keys.

**Architecture:** Pure display/filter helpers live in `dashboard-web/src/display.js` and use Node tests. FastAPI adds optional sector PATCH and append-only note-history operations. `stock_notes` remains the latest 3-axis snapshot, while `stock_note_history` stores immutable user submissions.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, PostgreSQL, React 19, Node test runner, pytest.

## Global Constraints

- Keep DB/internal keys unchanged for label localization.
- Preserve the three attractiveness axes without combining them.
- CORS must allow PATCH, DELETE, and OPTIONS.
- Convert NUMERIC values at DB boundaries and commit/roll back writes explicitly.
- Do not expose Python filenames or internal paths in UI copy.
- Update `PRD.md` §5.1, §11/change history and `CLAUDE.md`.
